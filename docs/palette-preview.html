05 — 衔接

暗底到白底，怎么过渡不脏

默认用“硬边 + 发丝线 + 呼吸间距”；需要更贵时用“白卡跨接”。不要用灰度线性渐变。

① 硬边 + 发丝线1px 白 8% + 上下 64–96px 留白
② 白卡跨接12px 圆角白卡上叠 32–48px，用结构过渡
✕ 禁用
③ 灰度渐变中间必然经过脏灰，4K 屏可见色带
暗区内部不要用 box-shadow 做抬升（不可见，只会糊边），用 night-800 + night-line。亮区之间不要用蓝色发光分隔。
